# Hailstone

Hailstone is a fork of [Hail](https://github.com/aistra0528/Hail), the open-source Android app for freezing and managing apps, shaped from the perspective of a UI/UX designer.

This fork approaches Hail from a product and interface design perspective. The goal is to preserve the power and reliability of the original app while making everyday interactions clearer, more flexible, and more pleasant to use.

## What is different?

Hailstone will evolve through focused UI and UX improvements. This section will grow as new changes are added.

### Added

- **Grid and list views on the Home screen** — switch between the original grid layout and a new list layout using the view menu in the toolbar.
- **Persistent view preference** — Hailstone remembers the selected Home screen layout after the app or phone restarts.
- **Custom Freezer lists** — create persistent named app lists and freeze only the apps in the opened list.
- **Focused list management** — add, edit, rename, or delete lists from dedicated screens without the primary navigation bar.
- **Searchable app picker** — add or remove apps with icons, selected-first ordering, search, and user/system or frozen/unfrozen filters.
- **List-level controls** — freeze, unfreeze, or unfreeze and remove every app in an opened list.
- **App actions and multi-select** — long-press an app for individual actions or select multiple apps for batch freeze, unfreeze, and removal from a dedicated contextual toolbar.
- **In-list search** — find apps inside an opened list using the same fuzzy, package-name, Nine-key, and Pinyin matching as Home.
- **Responsive frozen-state styling** — list icons and labels update immediately when app freeze state changes.
- **Hailstone branding** — the app now uses the Hailstone name throughout its primary user-facing surfaces.

## Project direction

Planned work will focus on:

- clearer navigation and information hierarchy;
- more consistent visual design;
- improved accessibility and usability;
- thoughtful customization without unnecessary complexity.

## About Hail

Hail is free and open-source software for freezing Android apps. Depending on the selected working mode and device permissions, it can disable, hide, suspend, or force-stop apps.

For original documentation, setup details, and technical information, visit the [upstream Hail repository](https://github.com/aistra0528/Hail).

## Status

Hailstone is an independent community fork and is not an official release of Hail. It is currently under active development.
